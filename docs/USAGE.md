# 轻饮水1.2.0使用说明

直接覆盖安装WaterLite-1.2.0.apk，不先卸载，可保留本项目旧版的登录和设备。

1. 使用慧生活798手机号、图形验证码和短信验证码登录。协议已对照life-798更新为设备端3.1.9及签名登录。
2. 右下角扫码添加；其上方是“图标＋刷新”，两者同尺寸圆角。右上角菜单提供手动添加、关于和退出登录。
3. 放好水杯，单击开始出水；再单击停止，无二次确认。软件自动检测状态，停止按钮保留红色。
4. 左划置顶/删除，长按改名。删除不改变云端收藏，再次扫码可恢复。
5. 清理后台后重新打开，会核实上次接水状态；设备明确已停且经过启动保护期时，首轮检测即可纠正旧状态。网络异常时保留停止能力，不凭时间假定设备已停。
6. 每次进入前台检查GitHub正式更新。发现更高版本时显示版本和更新说明，右下角“取消”“GitHub”；点击GitHub进入对应Release下载页。检查失败不会阻塞操作。

固定MIUI风格配色，不再随壁纸取色。浅色白色操作按钮与蓝色图标文字；深色柔和深蓝按钮与白色图标文字。圆角、按压、启停颜色过渡与滑动动画保留，遵循系统动画开关。

凭证加密保存在本机，临时错误不退出。服务端明确使凭证失效仍需短信验证；不能保证永久免登录。充值、签约等在官方应用完成。

模拟器使用模拟登录、余额与设备响应验证；真实手机的登录、扫码和饮水机仍需实测。
