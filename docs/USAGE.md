# 轻饮水 1.1.0 使用说明

将 WaterLite-1.1.0.apk 发送到小米15，打开安装。已安装本次交付的轻饮水1.0.0–1.0.2时直接覆盖更新，不用卸载，登录和设备会保留。首次安装时需要用慧生活798手机号登录。

1. 输入手机号、图形验证码，获取短信验证码后登录。
2. 登录后显示账号中的收藏饮水机。原应用仅保存在本机的设备需要重新扫码添加，登录凭证无法从旧应用自动迁移。
3. 右下角“扫码添加”扫描机身码，确认编号和名称后添加。右上角菜单也可手动输入编号。
4. 左划设备，图标和操作区会随手势渐显，松手后按位置和速度平滑展开或收起；置顶有卡片移位动画。删除只移除本应用快捷入口，不删除慧生活798的云端收藏；再次扫码可恢复。
5. 放好水杯，点击“开始出水”即发送出水命令，按钮变成红色“停止出水”；点击停止直接发送结束命令，两者都不需要二次确认。开始按钮现在跟随系统莫奈主色，按钮有颜色过渡和轻微按压动画。
6. 软件自动检查运行状态，不用手动刷新。运行中约每1.5秒检测；连续5次确认设备空闲后，自动恢复“开始出水”，避免设备启动时的延迟状态让按钮提前恢复。空闲设备也会自动检测。
7. 保留后台后返回软件会立即查询新状态。设备已过启动保护期、并明确返回空闲时，不再重新等待五轮；仍在运行时保留停止按钮。刚启动或网络失败时会继续核实，不会直接当作已停水。恢复速度取决于状态接口响应速度。
8. 手动刷新改成主页左下角的刷新图标，刷新时图标旋转。右上角菜单保留手动添加、关于和退出登录。长按设备可以修改名称。

Android12及以上全局跟随系统莫奈配色和深浅色，包括主页面、卡片、菜单、弹窗、输入框、扫码页及系统栏。取色由手机系统提供，具体颜色随系统壁纸或主题设置变化；停止出水保留红色，方便识别。Android8–11使用统一的深浅色回退主题。动画遵循系统动画开关，进入后台会停止播放；刷新保留列表滚动位置。

没有底部导航。保留设备状态、钱包余额和开关水，移除了教务、洗衣、积分任务、支付和提醒模块。充值、代扣签约、一卡通绑定仍在慧生活798完成。

已修复原应用“账号检查一失败就清空登录”的逻辑。断网、服务器临时错误、解析错误不会直接让你退出登录。服务端真正令凭证失效时，仍需要短信重新验证，已添加设备及置顶会保留；不能保证永久免登录。

安装包已验证签名；模拟器深色和浅色各69项检查通过，包含真实任务前后台切换、启动保护、慢请求取消、网络失败恢复、主题对比度、系统动画关闭及长列表滚动保持。出水和结束使用原软件相同的接口。测试中的账号、余额、开关水使用模拟响应；未测量小米15实机帧率，真实饮水机和相机仍需在手机上验证。
